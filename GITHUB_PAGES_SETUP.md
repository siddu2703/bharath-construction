# 🌐 GitHub Pages Setup Instructions

Your website is now live on GitHub! Follow these steps to enable GitHub Pages hosting.

## 📋 Setup Steps

### 1. **Enable GitHub Pages**
1. Go to your repository: https://github.com/siddu2703/bharath-construction
2. Click on **Settings** tab (top right of the repository)
3. Scroll down to **Pages** section in the left sidebar
4. Under **Source**, select:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Click **Save**

### 2. **Wait for Deployment**
- GitHub will automatically build and deploy your site
- This usually takes 1-2 minutes
- You'll see a green checkmark when it's ready

### 3. **Access Your Live Website**
Your website will be available at:
**https://siddu2703.github.io/bharath-construction/**

## 🔧 Optional Customizations

### **Custom Domain (If you have one)**
1. In the **Pages** settings, add your custom domain
2. Example: `www.sribharathconstruction.com`
3. Update your domain's DNS settings to point to GitHub Pages
4. Enable **Enforce HTTPS** for security

### **Update Repository Description**
1. Go to the main repository page
2. Click the gear icon next to **About**
3. Add description: "Sri Bharath Construction - Professional construction company website showcasing 20+ years of excellence in Chennai"
4. Add website URL: `https://siddu2703.github.io/bharath-construction/`
5. Add topics: `construction`, `website`, `chennai`, `responsive`, `html-css-javascript`
